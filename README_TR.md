# InstaRapor (Web)

Instagram ZIP arşivinden takipçi / takibi bırakan analizi yapan web uygulaması.

## Kurulum

```bash
pip install -r requirements.txt
python app.py
```

http://127.0.0.1:5000 adresini aç.

## Kullanım

1. Instagram’dan bilgilerini ZIP olarak indir (Bağlantılar / followers & following).
2. ZIP’i yükle.
3. “Beni geri takip etmeyenler”, “Benim geri takip etmediklerim”, çıkanlar ve gelen/giden karşılaştırmasını gör.

HTML ve JSON export formatları desteklenir. Veriler Instagram’a giriş yapmadan, senin yüklediğin arşivden okunur.
